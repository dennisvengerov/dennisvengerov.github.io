Overview

The model is PixNerd-XXL-P16-T2I (pretrained flow model). It predicts the velocity toward a clean image. I mix noise and image based on spec:

xt = (1 − t) ε + t x1

At t = 0, image is pure noise. t = 1 is clean image. The seed is 180, h = 0.02. CFG uses w = 7.

Part 1.1

Constructing noisy training inputs

My image is a steak. I reuse one noise ε. I also scale the image by t. Thus the noisy version looks greyer.

Part 1.2

Classical denoising

The first question is, can blur remove noise? First I divide by t. This restores the brightness. Then I apply a Gaussian blur. I tried the different sd, σ = 1, 2, 4, 8, 16. I kept the lowest MSE. The more noise needs more blur. But blur also removes image detail. At t = 0.25 it is a blob.

Part 1.3

One-step denoising

Now I use the model. Prompt: “a high quality photo”. This predicts a velocity towards manifold and not noise. One step to the clean image:

x̂1 = xt + (1 − t) vθ(xt, t, c)

As we see, much better than the blur. Still soft at high noise.

Part 1.4

Visualizing velocity

Another question: what does the model actually add? We saved the noise. So we know the true actual update. We can compare it to the prediction. Same scale, zero is gray. Error: RGB RMS per pixel. Same limits at every t. Error sits on the crust. It shrinks as t grows.

Part 1.5

Iterative denoising with Euler sampling

One step is a rough guess. The velocity changes along the way. So it makes sense if we take small steps:

xt+h = xt + h vθ(xt, t, c)

25 steps from t = 0.5. The last step is on t = 1.

Part 1.6

Generating images from noise

Same sampler, starts at t = 0. The prompt is “a high quality photo” with no guidance.

Every sample is a person. To this model photo means portrait lol. Quality is hit or miss. Seed 180 has no face. Seed 183 looks melted.

Part 2.1

Classifier-free guidance (CFG)

CFG runs the model twice. Once with the prompt. Once with an empty prompt. Then it pushes away from empty:

vcfg = vc + w (vc − vu), w = 7

Same five noises as 1.6.

As we see, every image is a clean headshot. The broken faces are gone. Some layout still carries over though. Seed 182 keeps the hand. The tradeoff here is diversity. All five look alike now due to strong guidance towards the prompt.
